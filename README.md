# DZ FlowPlay - Android IPTV Player

A premium IPTV player for your own playlists, built with Kotlin + Jetpack Compose. No root required.

## Features
- Xtream Codes + M3U playlist support, multiple providers
- ZyneLabs-style player: transparent chrome, centered transport cluster, info box with settings strip
- Channel drawer with category filters, EPG, catch-up, recording, PiP, multiview
- External subtitle (.srt) loader, sleep timer, playback speed, audio track selection
- D-pad / TV-remote friendly throughout
